TDV 2215 Terminal Emulator

Emulation of the TDV2215 terminal using original schematics, an emulated 8085 CPU and ROM dumps. Features TD2200 support with ESC sequence decoding, VT100 emulation, and keyboard mapping. Developed with Ghidra reverse engineering and Claude AI assistance via MCP bridge. Currently boots with remaining FLASH and interrupt handling issues. The browser version, RetroTermWeb, is written in TypeScript and covers both the TDV 2200 and the TDV 2215.
